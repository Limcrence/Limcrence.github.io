# 阅读进度同步后端

此 Worker 只存储加密进度。验证信息和加密密钥通过不同的 HKDF 标签从本地解锁密钥派生；服务端只验证授权令牌的 SHA256 是否匹配预先配置的 VAULT_ID。VAULT_ID 本身不是访问凭据。

GET 返回完整加密存档及版本号；PUT 必须携带已读取的版本号，D1 通过条件更新拒绝旧版本覆盖。mutationId 用于请求重试去重。

部署时参考 wrangler.example.jsonc，并在自己的 Cloudflare 账号创建专用 D1 数据库、执行 schema.sql。访问令牌、题库解锁口令、真实进度不写入配置或仓库。自定义域已通过控制台连接到生产服务，维护部署时保留这项配置。

真实数据同步前的集成测试使用独立本地数据库，测试接口不会写入生产存档。
